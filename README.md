# Caudate aging

Representative analysis notebooks and saved results from our study of caudate aging, human–macaque comparisons, and alcohol use disorder (AUD).

Each folder contains one example notebook and one result table:

| Folder | Analysis notebook | Result table |
| --- | --- | --- |

| `fig2_species_aging` | [Young–old pathway enrichment](fig2_species_aging/analysis/pathway_enrichment.rmd) | [Lu 2004 and MitoCarta reference enrichment](fig2_species_aging/results/gsea/GSEA_reference_old_vs_young.csv) |
| `fig3_aging_dynamics` | [Joint aging trajectories](fig3_aging_dynamics/analysis/joint_aging_trajectories.rmd) | [Trajectory cluster summary](fig3_aging_dynamics/results/dynamics/all_cluster_panel_summary.csv) |
| `fig4_aging_AUD` | [Metaprogram age × AUD models](fig4_aging_AUD/analysis/nmf_age_aud.rmd) | [Metaprogram model results](fig4_aging_AUD/results/NMF_age_AUD.csv) |
| `fig5_bulk` | [Bulk RNA-seq differential expression](fig5_bulk/analysis/bulk_differential_expression.rmd) | [Differential expression summary](fig5_bulk/results/DE_summary.csv) |
| `fig6_multiome` | [RNA, ATAC and motif age models](fig6_multiome/analysis/multiome_age_models.rmd) | [Feature test counts](fig6_multiome/results/native_dynamics/model_test_counts.csv) |
